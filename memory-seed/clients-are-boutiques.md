Clients are small to mid size boutiques. Many sell live through CommentSold (shoppers comment "sold" during a show), many run Shopify, and some run both, connected by My Ship Manager. Common tools beside the store: Meta and Instagram, Klaviyo, Pinterest, Google.

**Why:** the platform decides how inventory moves, what the inbox agent can look up, and which ads and email tools exist.

**How to apply:** every client profile states platforms. Never assume Shopify. For a client on both, Shopify is the inventory truth ([[shopify-is-the-inventory-truth]]).
