# Memory index

One line per memory. Every agent reads this file at the start of every session, then opens the memories that touch the task, starting with the ones tagged to its own space (listed in its folder's `CLAUDE.md`). Format and rules: `docs/memory.md`.

* [Who ThinkSocial is](who-thinksocial-is.md): the agency, what it is known for, and how it is staffed.
* [Desiree approves everything external](desiree-approves-everything-external.md): drafts are free; anything that leaves, spends or changes a live system needs her specific yes.
* [Service menu](service-menu.md): what the agency sells, so agents route and scope work correctly.
* [Clients are boutiques](clients-are-boutiques.md): online boutiques and live sellers on Shopify, CommentSold or both.
* [VAs never send without review](vas-never-send-without-review.md): agents draft, a person reviews, a person sends.
* [No holding replies by default](no-holding-replies-by-default.md): a client gets holding replies only when their profile says yes.
* [Password vault rule](password-vault-rule.md): 1Password, one vault per client, never a credential in a file.
* [Design system pointer](design-system-pointer.md): ThinkSocial's colors and type in one paragraph, and where the full system lives.
* [Prospect package pattern](prospect-package-pattern.md): a prospect store link means research, 10 sample ads, a proposal and a F.O.C.U.S. rundown.
* [Shopify is the inventory truth](shopify-is-the-inventory-truth.md): write stock to Shopify only; CommentSold follows through My Ship Manager.
* [Never overwrite a sheet](never-overwrite-a-sheet.md): every preference sheet is a new file; the last one is the format to match.
* [Example Boutique is fake](example-boutique-is-fake.md): the sample client exists to show the shape and is never real work.
