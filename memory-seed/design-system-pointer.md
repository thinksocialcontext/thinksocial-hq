Colors: ink #303030 for headings, coral #E34949 as the main action color, sky #A1D4DC as its quieter partner, slate #5C7988 and deep red #9F1D22 for links (deep red at rest, slate on hover), white for cards and button text. Type: Montserrat for headings, buttons and body; uppercase with letter spacing on headings and buttons. Aquatico is a rare accent display face. The signature device is a rounded pill behind a headline.

**Why:** proposals, reports and anything with the agency's name on it should look like the agency.

**How to apply:** use these for agency documents. A client's work uses the client's own brand file, never ours. Ask Desiree for the full design system file when building anything larger than a one pager.
