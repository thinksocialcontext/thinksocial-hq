Facebook and Instagram ads, Google ads, Pinterest, email marketing, SMS, graphic design, social media management, inventory management (data entry), virtual assistants, website design and redesign, CommentSold implementation, and dropshipping support. Newer agent offers sit beside these: an inbox drafting agent per client, a creative agent for ads, and AI search visibility.

**Why:** a client's profile lists which of these they buy; work outside that list is a scope question for Desiree, not something to start.

**How to apply:** use these names in `clients/INDEX.md` and in each `profile.md` under services. When a request falls outside a client's services, flag it as a possible upsell in the approval file rather than doing it.
