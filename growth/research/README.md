# Research file format

One file per job: `YYYY-MM-DD-<topic>.md`.

```
# <topic>

Objective: <from the brief>
Stop condition: <from the brief>
Ledger job: <id>

## Findings
* <finding>. Source: <link>. F.O.C.U.S.: <letter>
* "<verbatim customer quote>". Source: <link>

## Not verified
* <anything you could not confirm>
```
