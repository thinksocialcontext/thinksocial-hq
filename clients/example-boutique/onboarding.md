# Onboarding checklist: Example Boutique

Tick each line as `* [x]` when done. Anything waiting on the client goes in `kb/questions.md`.

## Week one
* [x] Profile filled: platforms, services, plan, price, start date, VA lead
* [x] Holding reply preference confirmed with the owner (default no)
* [ ] 1Password vault created for this client by ops; access listed per VA (`ops/vault-policy.md`)
* [x] Row added and correct in `clients/INDEX.md`
* [ ] VA lead and backup named in `team/roster.csv`

## Knowledge base
* [ ] Brand voice: tone, words they use, words they never use, sign off (`kb/brand-voice.md`)
* [ ] FAQ copied from the client's own site and handbook, with source links (`kb/faq.md`)
* [ ] Shipping, returns, exchanges, sizing, preorder and live sale policies (`kb/policies.md`)
* [ ] Open questions for the owner written down (`kb/questions.md`)

## Inbox agent
* [ ] `inbox-agent/prompt.md` placeholders filled from the profile and kb
* [ ] Draft only confirmed: the mailbox connection has read and draft access, no send
* [ ] First run's drafts read closely by the VA lead before anyone trusts the voice

## Inventory (if inventory management is in their services)
* [ ] `inventory/clients/example-boutique/preference.json` columns set
* [ ] Their last preference sheet saved to `inventory/clients/example-boutique/last/`
* [ ] Attribution rules in `inventory/rules/example-boutique.json`
* [ ] For Shopify and CommentSold clients: My Ship Manager default location noted

## Ads and reporting
* [ ] Ad accounts listed in the profile; read access only
* [ ] Monthly report day agreed
