# Onboarding paperwork checklist

## New client
* [ ] Agreement signed and stored
* [ ] Billing row added to `ops/billing.csv`
* [ ] 1Password vault created, approver named
* [ ] `scripts/new-client <slug>` run, `/client-onboard <slug>` started

## New VA
* [ ] Contractor agreement signed and stored
* [ ] Roster row in `team/roster.csv`
* [ ] 1Password access for their clients only
* [ ] First week plan (`team/sops/new-va-first-week.md`)
